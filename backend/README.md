# RSL Translator — промежуточный прототип

Основа общения двух пользователей. Python 3.13, FastAPI и простой браузерный
интерфейс на HTML, CSS и JavaScript. Оформление бело-чёрное.

## Первый запуск

В папке backend установи зависимости один раз.

```powershell
python -m pip install -r requirements.txt
```

Затем дважды нажми **Start.cmd**. Он запускает сервер при необходимости,
создаёт или переиспользует публичный HTTPS-адрес и открывает сайт.
Компьютер, интернет и окно туннеля должны продолжать работать.
Повторное нажатие открывает уже действующую ссылку.

Адрес выдаётся сервисом localhost.run и может меняться. Постоянный адрес и
работа при выключенном компьютере потребуют отдельного размещения сервера.

## Как подключиться вдвоём

1. Выбери «Жестовая речь» или «Устная речь» и нажми «Создать комнату».
2. Нажми «Скопировать» возле приглашения и отправь ссылку другу.
3. Друг открывает ссылку и нажимает «Подключиться к комнате».
   В приглашении указан противоположный режим.
4. Для проверки отправьте текстовое сообщение.
5. Для видеосвязи каждый нажимает «Включить камеру и микрофон» и разрешает
   доступ в своём браузере. Камеру и микрофон можно выключать отдельными кнопками.
6. «Выйти» закрывает соединение и освобождает устройства на этом компьютере.

В комнате по одному участнику каждого режима. Когда оба вышли, комната
удаляется. При перезапуске сервера комнаты тоже теряются.

## Текущее состояние

Добавлены комнаты, приглашения, переписка, выход, поддержание WebSocket-связи,
попытки переподключения и браузерный код WebRTC.
Камера включается по нажатию пользователя. Для доступа к устройствам нужен
HTTPS или localhost. Видео и аудио передаются браузерами.

Браузерный сценарий входа, текста, выхода и повторного входа проверен.
Передачу реальных устройств между двумя компьютерами необходимо испытать.
Сейчас настроен публичный STUN. Для сетей, требующих ретрансляции медиа,
понадобится TURN. Временный HTTPS-туннель публикует API и signaling.

ИИ-перевод, распознавание речи, обучение модели жестов, словарь видео,
PostgreSQL и Docker относятся к следующим этапам. Существующий MediaPipe
возвращает координаты рук через /hands и отдельный тест camera.py.

## Файлы

- mainFastAPI.py — HTTP, WebSocket, статические файлы и загрузка MediaPipe.
- rooms.py — комнаты и участники в памяти одного процесса.
- signaling.py — текст, WebRTC signaling и ping/pong для поддержания связи.
- index.html — структура страницы.
- static/style.css — простое оформление.
- static/room.js — вход, переписка, медиа и восстановление соединения.
- hand_tracking.py — существующее извлечение точек рук.
- camera.py — локальный тест веб-камеры в IDLE.
- start-public.ps1 и Start.cmd — запуск сервера и публичного доступа.
- test_backend.py — минимальные проверки API.
- ../FRONTEND_API.md — форматы запросов и событий.

## Запуск без публичного адреса

```powershell
python -m uvicorn mainFastAPI:app --host 127.0.0.1 --port 8000
```

Открой http://127.0.0.1:8000 в браузере. Для IDLE открой mainFastAPI.py,
нажми F5, затем выполни в Shell две строки.

```python
import uvicorn
uvicorn.run(app, host="127.0.0.1", port=8000)
```

Используй один процесс сервера, поскольку комнаты находятся в его памяти.

## Проверки

```powershell
python -m pip install "httpx>=0.28,<1"
python test_backend.py
```

Проверяются комнаты, роли, текст, signaling, ping/pong, отключения, загрузка
изображений и настоящий MediaPipe на пустом PNG. Инструкция по установке модели
и локальной камере находится в README-hands.md.
