# RSL Translator — backend

Python 3.13. Сервер создаёт комнаты на двух участников, передаёт текст и
WebRTC signaling, извлекает координаты рук из изображений через MediaPipe.

## Файлы

- `mainFastAPI.py` — HTTP, WebSocket, CORS и запуск/завершение модели.
- `rooms.py` — словарь комнат и участников, добавление и удаление участников.
- `signaling.py` — проверка и пересылка сообщений внутри комнаты.
- `hand_tracking.py` — существующие функции загрузки модели и получения точек.
- `hand_landmarker.task` — модель, лежит рядом с `hand_tracking.py`.
- `camera.py` — самостоятельный локальный тест камеры в IDLE.
- `requirements.txt` — серверные зависимости, включает `requirements-hands.txt`.
- `README-hands.md` — установка модели и локальная проверка камеры.
- `../FRONTEND_API.md` — договорённости для фронтенда.

## Установка и запуск

Открой PowerShell в папке backend. Используй тот же Python 3.13, что и IDLE.

```powershell
python -m pip install -r requirements.txt
python -m uvicorn mainFastAPI:app --host 127.0.0.1 --port 8000
```

Через IDLE открой `mainFastAPI.py` и нажми F5. Затем в IDLE Shell выполни
две строки. Окно Shell будет занято сервером до остановки через Ctrl+C.

```python
import uvicorn
uvicorn.run(app, host="127.0.0.1", port=8000)
```

Модель загружается один раз при старте и закрывается при остановке.
Запускай один процесс сервера. Комнаты находятся в памяти этого процесса
и пропадают после перезапуска. Пустая созданная комната ожидает первого
участника. После выхода последнего подключавшегося участника она удаляется.

## API

Базовый адрес `http://127.0.0.1:8000`.

| Маршрут | Действие |
| --- | --- |
| `GET /hello` | Возвращает строку `It works!` |
| `POST /rooms` | Возвращает `{"room_id": "случайный ID"}` |
| `GET /rooms/{room_id}` | `{"exists": true, "participants": 0}`, отсутствующая комната — 404 |
| `POST /hands` | JPEG/PNG, multipart, поле `file`, максимум 5 × 1024 × 1024 байт |
| `WS /ws/{room_id}?role=sign` | Вход участника с жестовой речью |
| `WS /ws/{room_id}?role=speech` | Вход участника с устной речью |

Пример ответа `/hands` по структуре одной точки (в действительном ответе
в каждой руке 21 точка).

```json
{"hands": [{"side": "Left", "points": [{"x": 0.42, "y": 0.67, "z": -0.03}]}]}
```

Если рук нет, ответ `{"hands": []}`. Изображения обрабатываются в памяти.
Общий размер multipart-запроса ограничен 5 МБ + 64 КиБ на заголовки.
Неправильный multipart или повреждённое изображение — 400, превышение
размера — 413, неподдерживаемый формат — 415.

При подключении WebSocket клиент получает `joined`, собеседник — `peer_joined`.
Участник может отправлять следующие сообщения.

```json
{"type": "text", "text": "Привет!"}
```

```json
{"type": "offer", "data": {"type": "offer", "sdp": "..."}}
```

Также поддерживаются `answer` и `ice_candidate` с объектом `data`.
Сервер отправляет сообщение только второму участнику своей комнаты.
При выходе собеседника приходит `{"type": "peer_left", "role": "sign"}`.
Ошибка сообщения возвращается как `{"type": "error", "message": "описание"}`.
Недопустимый вход отклоняется до WebSocket handshake с HTTP 403.

Для локального React разрешены CORS origins localhost и 127.0.0.1,
порты 5173 и 3000. При смене адресов обнови список в `mainFastAPI.py`.

## Следующие части приложения

Фронтенд должен реализовать WebRTC, доступ к камере/микрофону, STUN,
интерфейс комнаты и распознавание речи через доступный Web Speech API.
Для соединения в разных сетях позже понадобится TURN.
Перевод жестов в слова потребует отдельной обученной модели.
Сейчас `/hands` возвращает реальные точки, которые затем можно передавать
будущему модулю распознавания жестов. Маршрут предназначен для отдельных
изображений. Видео и аудио передаются между браузерами через WebRTC.

## Минимальная проверка

Из папки backend запусти проверку с настоящей моделью и чёрным PNG-кадром.
Камера для неё не нужна. `httpx` нужен только тестовому клиенту.

```powershell
python -m pip install "httpx>=0.28,<1"
python test_backend.py
```

Проверяются комнаты, два WebSocket-клиента, пересылка текста и offer,
отказ третьему участнику, удаление комнаты, `/hands` и ошибки загрузки.
Доступные части прототипа проверяются отдельно от будущего браузерного звонка.

## Доступ другу через интернет

Запусти сервер как обычно. Затем открой второе окно PowerShell в backend.

```powershell
powershell -ExecutionPolicy Bypass -File .\start-public.ps1
```

Скрипт использует встроенный Windows SSH и сервис localhost.run.
Передай другу напечатанную HTTPS-ссылку, добавив к ней /hello или /docs.
Другу достаточно браузера. Оставь оба окна и компьютер работающими.
Ctrl+C в окне туннеля прекращает доступ.

Бесплатный адрес временный, может меняться при переподключении и во время
работы сервиса. Для постоянного адреса и работы при выключенном компьютере
понадобится размещение backend на хостинге.
Ссылка даёт доступ к API приложения всем, кто её получил.

Документация сервиса — https://localhost.run/docs
